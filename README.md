# Домашняя работа 4. Перевод числа в римскую цифру

## Описание задачи

Программа просит пользователя ввести число от 1 до 12 и выводит его аналог римскими цифрами (I–XII). Если введено число вне диапазона (например, 0, 15 или буквы), программа сообщает об ошибке.

## Пошаговое описание работы программы

### Шаг 1. Подключение библиотеки

Подключается стандартная библиотека ввода-вывода, чтобы программа могла печатать сообщения на экран и читать числа с клавиатуры.

### Шаг 2. Объявление переменной

Объявляется целочисленная переменная n — в неё записывается число, введённое пользователем.

### Шаг 3. Приглашение к вводу

Программа печатает подсказку «Введите число от 1 до 12», чтобы пользователь понимал, какие значения допустимы.

### Шаг 4. Ввод числа

Функция scanf читает целое число с клавиатуры и сохраняет его в переменную n.

### Шаг 5. Выбор варианта (switch)

Оператор switch сравнивает значение n с перечисленными вариантами:

- варианты case 1 … case 12 соответствуют числам от 1 до 12;
- каждому варианту соответствует своя римская цифра: 1 → I, 2 → II, 3 → III, 4 → IV, 5 → V, 6 → VI, 7 → VII, 8 → VIII, 9 → IX, 10 → X, 11 → XI, 12 → XII.

Как только совпадение найдено, программа печатает соответствующую римскую цифру.

### Шаг 6. Выход из switch (break)

После каждого вывода стоит оператор break — он завершает работу оператора выбора. Без него выполнение «проваливалось» бы в следующий case и на экран попало сразу несколько строк.

### Шаг 7. Обработка ошибки (default)

Если n не совпала ни с одним вариантом (число меньше 1 или больше 12), выполняется ветка default: программа печатает «Ошибка». Это защита от некорректного ввода.

### Шаг 8. Завершение работы

Функция возвращает 0 — стандартный код успешного завершения программы.

## Общая логика

Ввод числа → switch по диапазону 1–12 → вывод римской цифры → break → при несоответствии — «Ошибка» → завершение.
